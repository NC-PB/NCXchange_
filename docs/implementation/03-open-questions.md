## Wave 1

Each question was checked against the whole documentation set. Where the documents already answer it, the Disposition column names the section and what the code must change, if anything. Where only the shape of the code is at stake, and no output, diagnostic, state or plugin surface depends on it, the column says "implementation". Every other question is drafted as a decision under "Still open" in `../decisions/rationale.md`; several questions can share one entry, and one question can need several. Until an entry is answered the code keeps the least committal workaround at the location in the last column; the answer, the specification change, the code and the removal of the marker go into one commit. The Question column is a one-line summary; the question in full is in the task log named in the Task column (the letter a or b is the part of the task). Sections are cited as the documents cite them (language 4.7 is `../spec/ncx-language.md` section 4.7, VM is `../spec/ncx-virtual-machine.md`).
