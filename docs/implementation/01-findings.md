# Findings against the specification

Status: 2026-09-11, from two read-throughs of the whole documentation set against the five example programs, the source programs and the four machine files, before any code. Thirty places where the documents disagree with each other or where an acceptance criterion cannot hold as written; the final review after the fourth round found two more (F31, F32, at the end). Each finding names the documents (sections as the documents cite them, line numbers of the 1.0 files where a sentence is quoted), the task that hits it first, and the resolution: a decision draft in `02-decisions-proposed.md` when the language, the virtual machine or the configuration changes, a document fix in the named task otherwise. The "resolved by" column is filled as the rows of `../decisions/decisions.md` and the commits land; on 2026-09-18 every row has it, with the commit where a task made the fix.

Nothing here is a criticism of the design; the design is consistent in what it means. These are the places where two documents wrote the same thing differently, or where an example was written before the rule that governs it.
