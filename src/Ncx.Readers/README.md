# Ncx.Readers

A reader turns one controller program into an `NcxProgram` (architecture 7; controller-mapping): a tokenizer for the controller's syntax, a small source-side state for what the controller leaves implicit, and the mapping to NCX words through the machine configuration (function tables, templates, cycle catalog). What it cannot read becomes `RAW` with a WARNING; nothing is dropped (architecture 2 rule 4, D5). One folder per controller family, `Fanuc/`, `Heidenhain/`, `Siemens/`, of small files named after what they map (`FanucCycles.cs`), and `ISourceRule`, the reader-side plugin interface (D106).

Start with `IReader.cs` and `ReaderBase.cs`. `ReaderBase.Read` is the skeleton every reader shares: the family's `ISourceTokenizer` cuts the file into `SourceBlock`s of `SourceWord`s, the family's `StructureOf` says what each block is for the file structure (`SourceStructure`, `StructureRole`), `StructurePass` lays out the reading plan (language 4.13: the file frame, programs and subprograms as sections, the code below `M30` in front of `PROGRAM=END` behind `JUMP=END`, the `M99` loop of controller-mapping 6, the contour a cycle names by a block range as a `SUB` section, `ContourOf`, D65), and each block is read in turn: `SourceState.Apply` with the family's modal groups, the configuration tables first and then the `ISourceRule`s for what they leave undecided (D40, D66, D105), then the family's `ReadBlock`. A family begins its blocks with `BeginBlock`, which adds `SKIP` and the source comment (controller-mapping 1), keeps what it cannot read with `EmitRaw` (`RawEmitter.cs`), and finds the machine's functions with `FindFunction`, codes compared by number (`NativeCode.cs`, D105). `ReaderRegistry` chooses the reader by the controller of the machine file; `ReadOptions` carries the rules.

The codes are `RDR001` to `RDR099` in `DiagnosticCodes.Raw.cs` and `DiagnosticCodes.Structure.cs`; a family takes a range of its own.

Never here: the meaning of a program beyond what the source leaves implicit (the virtual machine decides it, architecture 2 rule 1); code for one machine (machines differ in their TOML files, architecture 2 rule 2); NCX text written by hand (`NcxBuilder` and `NcxWriter` of `Ncx.Core`); generics of our own, LINQ chains of more than two calls, files longer than one screen (code-guidelines 10.2).
