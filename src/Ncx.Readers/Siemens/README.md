# Siemens

The reader of SINUMERIK 840D and 840D sl programs (controllers `siemens.md` 1 to 11; the Siemens column of every section of `controller-mapping.md`): one file per concern, so that an NC programmer finds `CYCLE800` in `SiemensTilt.cs` and `MCALL` in `SiemensCycles.cs`.

Start with `SiemensReader.cs`. It gives the structure pass the role of every block from the units of the file (`SiemensUnits.cs`: every `%_N_NAME_MPF` a program, every `%_N_NAME_SPF` and `PROC` a subprogram, every `_INI` unit a program of `RAW` blocks; the labels `NAME:` and the block numbers the jumps enter), writes the complete header of D34 after `PROGRAM=BEGIN`, and reads every block concern by concern into a `SiemensDraft` of NCX blocks: `SiemensRaw.cs` (`MSG`, `STOPRE`, `WORKPIECE`, `SETAL`, the synchronized actions, the interrupts, `$P_UIFR` writes, the recipe block of the STAMA post), `SiemensFlow.cs` (`GOTOF`/`GOTOB`/`GOTO` with `IF`, `CASE`, `GOTOS`, `REPEAT`, `DEFINE`) with `SiemensRepeat.cs` (the range of `REPEAT` and `REPEATB`, a `SUB` section the repeat calls where it does not end directly before it) and `SiemensStructures.cs` (`IF`/`ELSE`/`ENDIF`, `WHILE`, `FOR`, `LOOP`, `REPEAT`/`UNTIL` lowered to `LABEL`, `JUMP`, `IF`, or kept as `RAW` as a whole where the condition has no NCX form), `SiemensVariables.cs` (`R1=`, `DEF`, the names of the machine) and `SiemensCalls.cs` (`PROC`, `EXTERN`, `L100`, `NAME`, `NAME P3`, `CALL`, `EXTCALL`), `SiemensGroups.cs` (the G groups: `WORKPLANE`, `COMP`, `UNITS`, `FEED_MODE`, and the `RAW` modal words), `SiemensPolar.cs` (`G110`..`G112`, `AP=`/`RP=`), `SiemensFrames.cs` (`G54`.., `G500`, `TRANS`/`ATRANS`, `ROT`/`AROT`, `MIRROR`/`AMIRROR`, `SCALE`, `G58`/`G59`, `G74`/`G75`, `PRESETON`) with `SiemensChain.cs` and `SiemensTilt.cs` (`CYCLE800`, `ROTS`/`AROTS`), `SiemensTransformations.cs` (`TRAORI`, `TRACYL`, `TRANSMIT`, `TRAFOOF`, `DIAMON`/`DIAMOF`/`DIAM90`, `CYCLE832`, `CTOL`/`OTOL`), `SiemensTools.cs` (`T`, `T=`, `T="NAME"`, `M6`, `D`), `SiemensSpindles.cs` (`S`, `S2=`, `M3`, `M2=3`, `SETMS`, `G96`.., `LIMS`, `G26`, `SPOS`, `M19`, `M70`, `COUPON`/`COUPOF`), `SiemensChannels.cs` (`WAITM`, `INIT`/`START`/`WAITE`, `GROUP_BEGIN`), `SiemensCycles.cs` (the cycles through the catalog `cycles/siemens.toml`, `MCALL`, `CYCLE_F`) with `SiemensPatterns.cs` (`HOLES1`, `HOLES2`), `SiemensMotion.cs` (`G0`..`G3`, `G90`/`G91`, `AC()`/`IC()`, `DC()`, the extended axes, `F`, `FB`, `G4`, the tool vector) with `SiemensArcs.cs` (`I J K`, `I=AC()`, `CR=`, `AR=`, `TURN=`, `CIP`, `CT`) and `SiemensCorners.cs` (`CHF`, `CHR`, `RND`, `RNDM`, `ANG`, D58), and `SiemensFunctions.cs` (the M functions through the machine's tables, `MFUNC`, the `H` words). Every word a concern reads is marked in `SiemensBlock`; a word that no concern reads keeps its block as `RAW` with a WARNING, so nothing is dropped (D5).

`SiemensTokenizer.cs` with `SiemensScanner.cs` cuts the file into blocks (unit headers, `;` comments, `/n`, `N`, labels, the words with `=` and extensions, call argument lists, `DEFINE` macros), `SiemensFacts.cs` holds what the reader knows of the modal state of the control, and `SiemensState.cs` the file with its units, the structures the reader is inside and the states the calls enter a subprogram with (virtual machine 3.9). The codes are `RDR500` to `RDR699` in `../DiagnosticCodes.Siemens.cs`.

Never here: `ncx convert` (`Ncx.Cli`), the meaning of the program beyond what the source leaves implicit (the virtual machine), code for one machine (its TOML file and the cycle catalog), the GILDEMEISTER structure programming (D68: documented in `docs/controllers/machine-builders.md`, not implemented).
