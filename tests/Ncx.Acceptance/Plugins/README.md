# Plugin tests

The tests of `src/Ncx.Plugins/` (implementation 17, P7-01). `TestPlugins/` holds two plugin projects, which `../Ncx.Acceptance.csproj` builds before the tests without referencing them and copies into `TestPlugins/` of the output folder: `ShopRules`, the plugin a shop builds from the template of code-guidelines 11 (the `CoolantClutchRule` as printed there, a rewriter that reads its settings, a reader rule, a listener, a block writer), and `FaultyRules`, whose classes throw or insert a text that does not parse, each on a word of its own. `TestPlugins.cs` copies them into a folder of the test and loads them from there; `PluginMachines.cs` holds the mill with and without the clutch rule of machine-config 5a; `EchoCompiler.cs` compiles every block as its NCX line.

Open first: `CoolantClutchPluginTests` and `FailingPluginTests`, the two "Done when" of P7-01; then `PluginLoaderTests` (contexts, shared `Ncx.*` assemblies, load order, settings of D80), `ListenerPluginTests` (Before and After, read-only), `PluginWiringTests` (check, trace, convert and compile with plugins in `plugins/` and in `ncx.toml`) and `PluginDiagnosticCodesTests` (`PLG` codes of D98).

The tests of the plugin template and the `ncx plugin` commands (implementation 17, P7-02) work in a folder of their own through `PluginWorkspace.cs`, with the folder of the test run as the folder of ncx, where the build puts the Ncx assemblies and `templates/ncx-plugin/`. Open first `TemplateTests`, the "Done when" of P7-02: `BuiltTemplate.cs` runs `ncx plugin new CoolantClutch` and `ncx plugin build` once, and the tests check the DLL in `plugins/` and the line in `ncx.toml`, `ncx plugin check`, the INFO of `ncx compile` at line 12 and `ncx plugin test`; these and `TemplateMistakeTests` run dotnet of the .NET SDK. Then `PluginNewTests`, `PluginCheckTests`, `PluginFolderTests`, `PluginCommandLineTests`, `NcxTomlPluginsTests` (the line of `ncx.toml`) and `TemplateFilesTests` (the template against code-guidelines 11 and against the samples of `samples/plugins/`).
