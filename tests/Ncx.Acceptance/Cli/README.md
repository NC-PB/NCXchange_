# CLI tests

The commands of `src/Ncx.Cli/Commands/` through `Program.Run`, with the exit codes of D97 and the diagnostics on the standard error in the form of D98, each test in a temporary folder of its own: `ncx format` (`FormatCommandTests`), `ncx check`, `ncx trace` and `ncx annotate` on every example and on small files (`CheckCommandTests`, `TraceCommandTests`, `AnnotateCommandTests`, and `TraceInterpretedTests` for `trace --interpreted` with `--vars`, with `CliHarness` for the folder and the outputs and `TestMachines` for the machine files given by path), `--strict` on every command (`StrictOptionTests`), and the stages the three share (`PipelineTests`). The machine of a run (P2-04) is tested through `CheckCommand.Run` with a working directory and a tool folder of the test's own (`ProjectHarness`): `--machine` by name in the machine folders or by path (`ProjectFoldersTests`), and `ncx.toml` and the cycle catalog of the machine (`RunMachineTests`). `ncx convert` is tested through `ConvertCommand.Run` in the same way (`ConvertCommandTests`): the machine it requires, the reader of its controller, `--output`, and the diagnostics of the reader and of the check. `ncx analyze` (`AnalyzeCommandTests`) runs on every example, writes the reference reports of `../Expected/analytics/`, and checks its options: the block range, `--analytic`, `--static`, `--vars`, `--format csv`, `--strict`. `ncx compile` is tested through `CompileCommand.Run` in the same way (`CompileCommandTests`), with `RecordingCompiler` as the compiler of the machine's controller: the machine it requires, the compiler of its controller, the files under `out/<machine>/` or in the folder of `--output`, and the tool table of D10. `ncx convert --batch` is tested through `BatchCommand.Run` and the command line (`BatchCommandTests`): every file of a folder and of its folders, a crash and an ERROR that never stop the batch, the folder and the machine it requires, the usage errors of `--batch` and `--report`, the report, and the reports of `docs/spec/examples/sources/` in `../../corpus-reports/`, which it writes when they differ. `DiagnosticCodesTests` checks the `CLI` codes. A new command of `src/Ncx.Cli/Commands/` gets its test file here.
