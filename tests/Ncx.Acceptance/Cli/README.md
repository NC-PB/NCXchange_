# CLI tests

The commands of `src/Ncx.Cli/Commands/` through `Program.Run`, with the exit codes of D97 and the diagnostics on the standard error in the form of D98, each test in a temporary folder of its own: `ncx format` (`FormatCommandTests`), `ncx check`, `ncx trace` and `ncx annotate` on every example and on small files (`CheckCommandTests`, `TraceCommandTests`, `AnnotateCommandTests`, with `CliHarness` for the folder and the outputs and `TestMachines` for the machine files given by path), `--strict` on every command (`StrictOptionTests`), and the stages the three share (`PipelineTests`). `DiagnosticCodesTests` checks the `CLI` codes. A new command of `src/Ncx.Cli/Commands/` gets its test file here.
