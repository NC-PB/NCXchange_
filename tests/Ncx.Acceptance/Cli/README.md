# CLI tests

The commands of `src/Ncx.Cli/Commands/` through `Program.Run`, with the exit codes of D97 and the diagnostics on the standard error in the form of D98, each test in a temporary folder of its own: `ncx format` (`FormatCommandTests`), `ncx check`, `ncx trace` and `ncx annotate` on every example and on small files (`CheckCommandTests`, `TraceCommandTests`, `AnnotateCommandTests`, and `TraceInterpretedTests` for `trace --interpreted` with `--vars`, with `CliHarness` for the folder and the outputs and `TestMachines` for the machine files given by path), `--strict` on every command (`StrictOptionTests`), and the stages the three share (`PipelineTests`). The machine of a run (P2-04) is tested through `CheckCommand.Run` with a working directory and a tool folder of the test's own (`ProjectHarness`): `--machine` by name in the machine folders or by path (`ProjectFoldersTests`), and `ncx.toml` and the cycle catalog of the machine (`RunMachineTests`). `ncx convert` is tested through `ConvertCommand.Run` in the same way (`ConvertCommandTests`): the machine it requires, the reader of its controller, `--output`, and the diagnostics of the reader and of the check. `DiagnosticCodesTests` checks the `CLI` codes. A new command of `src/Ncx.Cli/Commands/` gets its test file here.
