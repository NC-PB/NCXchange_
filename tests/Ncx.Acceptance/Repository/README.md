# Repository tests

Rules of the repository that every build keeps: `ReferenceGraphTests` reads the project files and asserts the dependency diagram of architecture 3 and the package rule of code-guidelines 9; `FixtureTests` asserts that the embedded examples equal `docs/spec/examples` byte for byte (`../../README.md`, Fixtures); `ReadingTheCodeTests` asserts that every file and folder the guided tour `../../../docs/reading-the-code.md` names exists, and that its route runs from `Program.cs` through `format` and `check` into the virtual machine (P0-07; the conventions are in the last section of the tour); `LineLengthTests` asserts that no line of a C# file under `src/` or `tests/` is longer than the 120 characters of code-guidelines 3.3, which dotnet format does not check, and names the file and the line of each that is (wave-1 question #2, D109).
