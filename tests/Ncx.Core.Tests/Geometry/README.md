# Geometry tests

`Vec3Tests`, `PlaneTests` and `AngleTests`, and the three forms of `ARC` in `ArcCenterFormTests`, `ArcRadiusFormTests` and `ArcAngleFormTests` (virtual machine 3.2; D36, D84). `PolarFaceHexagonTests` walks the hexagon of `POLAR_FACE.ncx` as geometry (D60, D102). `GeometryAssert` compares doubles within a precision far below the arc tolerance.
