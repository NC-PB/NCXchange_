# Expander tests

The expander of `../../../src/Ncx.Core/Expander/` (virtual machine 1, 3.10; language 4.15; machine-config 5a; architecture 5.5): the expansion rules of a machine file on the tool change, a function state and a catalog cycle, `{position:NAME}` among them (`ExpansionRuleTests`, D63, D100), the coolant clutch of machine-config 5a as a rule (`CoolantClutchRuleTests`), the program rewriters of the plugins and their three answers (`ProgramRewriterTests`, D106), `limits = "clamp"` (`LimitClampTests`, D64), a generated block with its origin, its originating line in a diagnostic and its pseudo-words (`GeneratedBlockTests`; D95, D98), and the five examples through the expander (`ExampleExpansionTests`).

Open first: `CoolantClutchRuleTests`, the shop-floor example: `@SAVE`, the spindle stopped, the coolant, `@RESTORE`, and the state after it. `ExpanderHarness` parses, expands and runs a text; `ExpanderMachines` builds the machines with their rules by hand, because this project loads no TOML. The rewriters are small classes of the kind a plugin is: `CoolantClutchRule`, the example of the plugin template (code-guidelines 11), `ReplacingRewriter`, `SurroundingRewriter` and `ContextRecorder`.
