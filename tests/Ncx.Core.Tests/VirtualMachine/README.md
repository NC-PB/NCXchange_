# Virtual machine tests

Block execution, one test per rule: `ToolChangeTests` (one per row of virtual machine 3.5 and per transition of architecture 5.2), `ModalSummaryTests` (one per row of virtual machine 4), `FrameChainTests` and `SetposTests` (2.1, 3.4; D31, D101), `HomeTests` (D100), `MotionTargetTests` (3.1; D99), `ArcTests` (3.2; D36, D60, D84), `PolarCylinderTests` (D102, with the hexagon of `POLAR_FACE`), `VectorWordTests` (D81), `RetractTests` (3.1a), `CycleCallTests` (3.3; D37, D59, D94), `SetposMotionTests` (the setpos shift of D101 under the motions), `TurnedFrameMotionTests` (a motion under `ROTATE`, `TILT` or `TILT_AXIS` leaves the axes known in the MACHINE frame that it does not name as they were, 3.4), `ResourceResolutionTests` (3.8; D103), `DiameterRulesTests` (D60), `StaticRunTests` (D99, D53), `InterpretedFlowTests` (the flow of 3.6: jumps, calls, repeats, the depth, the block cap, `SKIP`), `InterpretedExpressionTests` (the values STATIC leaves UNKNOWN resolved, the vars file and the `SYS_` names; D38, D51), `ExternalProgramTests` (`CALL` of an external program, 3.6) and `InterpretedExampleTests` (`PATTERN_LOOP` and `INCREMENTAL_SUB` run INTERPRETED), with `InterpretedHarness`, `WordHandlersTests` (every state word has a handler), `RestoreStackTests` (`@SAVE` and `@RESTORE`, 3.10; D95), and `ExampleRunTests` (the five examples run STATIC without a machine file and give no ERROR). `Validation/` holds one test per rule of the validation list of virtual machine 5 and writes `docs/spec/generated/diagnostics.md`.

`VmHarness` executes blocks one by one or runs a whole file; `StateAssert` compares two states by what the program set; `VmMachines` builds the machines of these tests by hand, because this project loads no TOML. The tests of the state tables themselves are in `State/`, those of the events in `Events/`.
