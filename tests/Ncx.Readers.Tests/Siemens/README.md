# Siemens

The tests of the Siemens reader (`src/Ncx.Readers/Siemens/`): a snippet of SINUMERIK 840D sl code in, the NCX blocks out, one test per rule of `controllers/siemens.md` 11 and per cell of the Siemens column of `controller-mapping.md`, named after what the reader does with the words (`TRANS_ThenATRANS_CutsChainThenAppends`, `MCALLCYCLE81_PositionsBecomeCycleCalls`, `SETMS2_BindsBareSToSpindle2`).

`SiemensRead.cs` reads a snippet framed as the main program `%_N_TEST_MPF` with `M30` against the 840D sl mill of `machines/siemens-840dsl-mill.toml`, the mill-turn `machines/millturn1.toml`, or that mill with a rotary table of two axes for the rotary-axes mode of `CYCLE800`, each with the cycle catalog `cycles/siemens.toml`, and gives the blocks between the header and `PROGRAM=END`; `CheckedBody` gives them once check has run the whole program the reader wrote without an ERROR, which the tests whose output carries tools, motion or flow use. The files follow the rules of siemens 11: `SiemensProgramTests` (rules 1 and 6: the units, the archives, the ends, the labels, the skip levels, the comments), `SiemensMotionTests` (rules 2 and 9: the arcs, the polar coordinates, the corners of D58, the feeds), `SiemensToolTests` (rule 3), `SiemensFrameTests` (rule 4, the reference points, the diameter, the transformations), `SiemensCycleTests` (rule 5), `SiemensFlowTests` (rule 6), `SiemensChannelTests` (rule 7), `SiemensRawTests` (rule 8); `SiemensTokenizerTests` the syntax of section 1 and rule 9.

The two hand-written 840D sl programs end to end and the runs over the corpus are in `../../Ncx.Acceptance/Examples/SiemensReaderTests.cs`.
